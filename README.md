## Mono

Mono is a 2D game toolkit, providing functionality for:
* Drawing things onto screen (primitives, textures, text)
* Input system
* Logging
* Platform independent storage utilities for file reading and writing
* Playing audio 
* Built-in dev console
* Clock utilities for timing
* Tween functions
* Built-in Entity/Solid system
* UI
* Networking (eventually)

It only relies on SDL3 and OpenGL.

OpenGL backend is pretty alright, could be optimized more but implementing all in Vulkan would be easier.
So perhaps Vulkan support eventually (if I want to pick this project back).

There are some usage example projects: Bullet Game and Mono.GameTest.
